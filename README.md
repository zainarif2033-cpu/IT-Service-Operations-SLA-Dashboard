# IT Service Operations & SLA Dashboard
## Overview
This Power BI dashboard provides an enterprise level view of IT Support Desk performance across four communication channels: **Calls**, **Chats**, **Emails**, and **Escalations**. It tracks resolution efficiency, monitors SLA thresholds, and identifies top issue categories per channel.
## Key Features
## SLA Performance Tracking:
Standardized 24-hour resolution SLA ($\le 24$ hours = Met | $> 24$ hours = Missed) visualized using Clustered Bar Charts.
## Categorical Insights:
Custom binning and `Top N` dynamic filters highlighting top incident categories (Building, Account, Shipping, Product Inquiry,Feedback) for each channel.
 ## KPI Metrics:
 Instant visibility into SLA Met counts, Missed counts, and Average Resolution Time (in hours).
 ## Interactive Control:
 Top right Category slicer for multi categories data.
